# Gestura

A computer-vision desktop application that uses a webcam to recognize
hand movements and turn gestures into interactive visual controls.

## Overview

Gestura explores a more natural way to interact with a computer by using
hand gestures. It uses webcam input to recognize movement and map
gestures to visual actions in the application.

## Key Features

-   Webcam-based interaction.
-   Gesture-driven controls.
-   Interactive trails, objects, and visual effects.
-   Controls to clear or change the visual scene.

## Why This Project?

Gestura explores computer vision and human-computer interaction by
combining visual input, gesture interpretation, and interactive
feedback.
